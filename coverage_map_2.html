Circulation Coverage Atlas

Load your own GIS-apportioned panel below to see, district by district, how complete its public-library circulation record is for any fiscal year 2009–2024. Nothing is uploaded anywhere — every file is parsed and mapped entirely in this browser tab. Add the optional SEDA file for place names and grade 3/6 reading achievement in each district's tooltip.

Expected filenames from the build pipeline: district_centroids_full.csv, district_weights_by_system_v2.csv, district_year_library_gis_v6.csv, and optionally seda_filtered_2025.csv — any CSV with matching columns works. A district counts unmatched if it never appears in file 2; for a year it has a row for in file 3, it's full when both totcir and a children's-circulation column are present, partial when only totcir is, and matched, no data when neither is (or there's no row that year at all). File 4 is never required to build the map — it only enriches the hover tooltip, and Texas/Hawaii/Puerto Rico districts won't have a SEDA match at all (a documented gap in SEDA itself, not a loading error).

If this page sits in the same folder as those CSVs (file 4 included), it tries to read them automatically on open — no picking or dropping needed. Opening the file with a plain double-click blocks that in some browsers (Chrome in particular refuses local-file reads for security reasons); if the boxes above don't fill in on their own, either drag each CSV onto its box, or run one command from that folder and open the page through it instead: python3 -m http.server 8000, then visit http://localhost:8000/coverage_map.html.

With file 4 loaded, a district that would otherwise be full-blue drops a tier on any year SEDA itself covers if its reading achievement is incomplete — hover a district for the specific reason. Years SEDA has no data for at all (2020 and 2021, nationwide) never trigger this — only real gaps do.

Alaska is redrawn at its own scale in the inset (its longitude span would otherwise flatten the mainland). Single-district outliers whose coordinates fall far outside both frames — Hawaii, Guam, the Northern Mariana Islands, American Samoa — are counted in the totals above but omitted from the plot itself; Puerto Rico renders at the map's southeast edge.
