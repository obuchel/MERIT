Circulation Coverage Atlas

Load your own GIS-apportioned panel below to see, district by district, how complete its public-library circulation record is for any fiscal year 2009–2024. Nothing is uploaded anywhere — the three files are parsed and mapped entirely in this browser tab.

Expected filenames from the build pipeline: district_centroids_full.csv, district_weights_by_system_v2.csv, district_year_library_gis_v6.csv — any CSV with matching columns works. A district counts unmatched if it never appears in file 2; for a year it has a row for in file 3, it's full when both totcir and a children's-circulation column are present, partial when only totcir is, and matched, no data when neither is (or there's no row that year at all).
